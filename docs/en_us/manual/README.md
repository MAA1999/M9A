# User Manual

This manual is for people using M9A. It covers the whole path from installation to daily use. If you are new to M9A, read "Getting started" first; if something is already broken, jump straight to the FAQ.

## Getting started

- [Getting Started](newbie.md) — check your system version, install the runtime environment, unpack the release, connect an emulator, and run your first task.
- [Connection Settings](connection.md) — how to fill in the ADB path and connection address by hand when auto-detection fails, plus connecting to the global PC client.

## Features and tools

- [Feature Introduction](introduction.md) — what each automated task does and which options it exposes.
- [MirrorChyan Usage Guide](MirrorChyan.md) — getting updates and faster downloads through MirrorChyan.
- [MaaPiCli Usage Instructions](cli.md) — installing and using the command-line build.

## Troubleshooting

- [Frequently Asked Questions (FAQ)](faq.md) — download and installation failures, crashes while running, missing runtime libraries, the Agent taking too long to start, resource loading problems, and connection problems.
