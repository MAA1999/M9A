# Task Overview

The task-related panels are `Task List`, `Task Settings`, and `Task Description`.

The three buttons at the top-right of the task list are select all, deselect all, and add task.  
Tasks can be freely added, removed, and reordered. Left-click a checkbox to select a task; right-click it to run it once.  
Select a task to see its options and descriptions. Options are grouped into regular and advanced sections.  
**In particular, read the task description before running a task. Some tasks—those added after Outside Deduction—run independently and must be started from the specified game screen.**
