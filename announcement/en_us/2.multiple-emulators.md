# Multiple Emulators

Users often ask why another emulator instance cannot connect or start automatically.  
The documentation covers this in detail, but here is a quick summary.

## ADB Connection

![Main interface](announcement/images/newbie-main-interface.png)

The screenshot above shows the main interface. The connection control in the top-right corner is the part to focus on here.

ADB, the Android Debug Bridge, is how M9A connects to the emulator. If it is not configured correctly, no tasks can run.

Normally, opening the emulator and selecting **Refresh** is enough for M9A to discover and connect to it. For manual setup, see [Connection Settings](https://1999.fan/en_us/manual/connection.html).

**Note**: Multiple emulator instances may expose multiple controllers. Choose the right one! Use the second page on the left side of M9A, take a test screenshot there, and confirm that the connection is correct.

## Start Emulators with M9A

Use the button in the bottom-left corner of M9A to open settings. The startup settings control actions before and after startup.

The before-startup actions are **Start Application** and **Start Application and Script**. Here, “application” means the emulator, while “script” means M9A.

For **Application Path**, enter the emulator executable. For MuMu 12, use:

|             Old MuMu 12              |                     New MuMu 12 V5                     |
| :----------------------------------: | :----------------------------------------------------: |
| `{install-dir}\shell\MuMuPlayer.exe` | `{install-dir}\\nx_device\12.0\shell\MuMuNxDevice.exe` |

Then set the **Extra Command**. This is the key to launching the correct emulator instance; an incorrect command usually launches the base instance instead.

| Emulator |     Command format      |  Example  |
| :------: | :---------------------: | :-------: |
|   MuMu   |       `-v index`        |  `-v 1`   |
|  LDPlay  | `index=instance-number` | `index=1` |

Instance numbers start at 0. `0` is the base emulator, `1` is the first clone, and so on.
